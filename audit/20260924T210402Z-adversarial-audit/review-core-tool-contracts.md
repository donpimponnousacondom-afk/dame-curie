Add the exact `## Available tools\n` system-message prefix to the protected set, retaining the source-owned start check (not the previous overbroad `in` substring). Extend existing `tests/test_tts_silent.py::test_prompt_budget_trims_large_background_blocks` with a custom-catalog block and a schema-overflow case. Existing `tests/test_tts_silent.py::test_dispatch_native_records_tool_history_in_memory` (`:266-350`) checks prefixed plugins **only after** binding `TOOL_GROUPS_CONTEXT` to `{"plugins"}`. Extend that same case for undiscovered-but-eligible exact `tool_bash`; assert the builtin shell did not run and replay kept the original name.
3. **Blocker — malformed nonfinite JSON values still pass strict native admission (C-02/C-18).** `tool_schemas.py:1067-1070` uses default `json.dumps` for direct argument dictionaries and `:1086` uses default `json.JSONDecoder()` for strings. Both defaults accept nonstandard `NaN`/`Infinity` constants; `{"value":NaN}` (or a direct dict with a nonfinite float) passes the full-object/key/depth checks and can be executed alongside valid sibling calls, then replayed as a nonstandard JSON argument string. Require finite JSON numbers in both admission shapes before any execution. Extend `tests/test_tool_calls.py::test_normalize_native_tool_calls_decodes_provider_argument_shapes` with string/direct-dict nonfinite values and whole-batch rejection. This finding is from stdlib decoder/encoder defaults and source control flow, **not** from a runtime test.
4. **Blocker — persisted tool *result* metadata still slices embedded media (C-20).** The new recursive omission at `bot.py:13910-13956` sanitizes copied *parameters*. `bot.py:14239-14254` nevertheless passes raw `line` to `_remember_tool_call`, where `:13985-14012` stores the first/last 4k characters of *result*, including fragments of a `__IMAGE_B64__...__END_IMAGE_B64__` or audio marker, before later replay-media extraction. This is bounded in length but is neither a truthful media omission nor usable media. Replace entire embedded payload in persisted result metadata with a truthful type/size marker before length capping; keep execution result and admitted model-facing media separate. Existing `tests/test_tts_silent.py::test_dispatch_native_records_tool_history_in_memory` (`:286-347`) asserts nested *argument* redaction only; extend it with embedded result media and stored-result assertions. Author handoff `implementation-core.md:42` explicitly does not claim this path is covered.
